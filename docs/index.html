Why you'd use it

One camera, any viewer

MediaMTX is a popular open-source media server. This app runs it on the camera, with a web interface so you never need a terminal.

I just want to watch it in a browser

Open the stream with WebRTC or HLS in any modern browser, on a laptop or a phone, without plugins or a separate server.

My software wants a plain RTSP stream

Republish the camera on a stream name you choose, for an NVR, Home Assistant, VLC or anything else that speaks RTSP.

I need the clip from 14:32 yesterday

Pick the day on the recordings timeline, click the moment you want, drag to select a range, and download it as an MP4.

Features

Everything in the browser

📡

Every common format

RTSP for software and NVRs, WebRTC for low-latency browser viewing, HLS for everything else. RTMP and SRT are available when you need them.

📝

Settings editor built in

Edit the MediaMTX configuration in the browser with syntax highlighting, then save and restart. No SSH needed.

🗓️

Recordings timeline

See each day's recordings on a 24-hour bar, click to play from any moment, and export a selection as MP4.

🛟

Hard to break

Every save keeps a backup, and the page warns you if a new configuration stops MediaMTX from starting.

⬆️

Survives upgrades

Your configuration is kept when you install a new version.

🛡️

No root, fewer open ports

Runs as a normal app without root. RTMP, SRT and other extras stay off until you turn them on.

Install

Up and running in a few minutes

1
Download the packagePick AARCH64 or ARMv7 above.
2
Install it on the cameraIn the camera's web interface, go to Apps → Add app, upload the file and start the app.
3
Add a streamClick Open. In the settings editor, uncomment the example for this camera, fill in a camera account that can view video, then Save & Restart.
4
Watch itThe Live page lists your streams with WebRTC and HLS players and a copyable RTSP address.
5
Record (optional)Choose where recordings go (SD card or disk) and turn recording on for the stream. They appear on the Recordings page.
Questions

Good to know

Can I watch from outside my home or office network?

Yes, if the viewer can reach the camera. The simplest safe way is a VPN app on the camera, such as Tailscale, rather than opening ports on your router.

Is it secure?

The settings and recordings pages use the camera's own admin login. The media ports and MediaMTX's control interface don't, so keep the camera on a trusted network or behind a firewall.

Will recordings survive a reboot?

Yes, when they're stored on the SD card or disk. The settings include the right location for both; the README explains how to check it.

Will an update wipe my settings?

No. Your configuration is stored separately and kept when you install a new version. Uninstalling the app does remove it, along with its recordings.

Did you make MediaMTX?

No. MediaMTX is developed by the bluenviron project. This app packages it for Axis cameras and adds the web pages.
